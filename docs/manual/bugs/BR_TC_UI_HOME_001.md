# Bug Report: Homepage — Incorrect Headline Text in Featured Items Section

## Bug Information

| Field | Value |
|---|---|
| Bug ID | `BR_TC_UI_HOME_001` |
| Evidence | [Homepage screenshot](../evidence/TC_UI_HOME_001_homepage.png) |

## Description

The Automation Exercise homepage contains a typographical error in the Featured Items section heading.

## Steps to Reproduce

1. Open the Automation Exercise homepage.
2. Scroll to the Featured Items section.
3. Observe the section heading.

## Expected Result

The section heading reads `Featured Items`.

## Actual Result

The section heading displays `Features Items`.

## Environment

- Application: Automation Exercise website
- URL: `https://www.automationexercise.com/`

## Impact

The typographical error affects the clarity of the section heading and may confuse users.
